# v1.76.0 更新说明

本版集中修复社区反馈的 5 个问题：Qoder 渠道签名器闪退/领奖失败、反向映射同名拦截、Docker 版添加账号引导，以及 Windows 11 闪退的取证与同步托底。

## Qoder 渠道

- **修复使用 Qoder 渠道时应用闪退（#147）**：签名器补丁不再把客户端 worker 主循环带进主进程；首次加载会在子进程自检，失败时只标记渠道不可用，不再退出整个应用。已缓存的旧补丁会自动重建。
- **修复中文计算机名导致 Qoder 领奖失败（#148）**：领取/签到请求的设备名头按 ByteString 安全编码，中文机器名不再触发 `Cannot convert argument to a ByteString`。

## 反代网关

- **修复反向模型映射误拦（#145）**：实际模型与统一请求名相同、且是该渠道原生模型时，按恒等映射正常转发；大小写不同不再被静默丢弃。非原生虚拟名透传仍会被拦截。

## Docker / 号池

- **添加账号引导修正（#143）**：桌面端「导出选中账号」是元数据（不含 token），容器导入现在会明确提示改用号池同步或含 token 的凭据 JSON，不再报“没有可导入的账号”；容器 Web 控制台隐藏不可用的 OAuth/文件/本机导入入口，并给出三条可行路径。修正 OAuth 的「粘贴回调地址」错误提示与相关文档。

## 稳定性与取证

- **Windows 11 闪退取证与同步托底（#146）**：启动阶段原生组件加载失败会弹窗并写日志，不再留下无窗口进程；记忆中枢启动失败不再静默；崩溃日志增加内存占用/高水位、同步持锁超时与各模块 WebDAV 配置留痕。修复本地统计与远端同步并发时取消信号互相覆盖的问题。
- 打包配置显式解包原生模块，降低 asar 临时解包被杀软拦截的概率。

## 说明

- #146 的具体崩溃点仍需用户回传 `%APPDATA%\AgentHub\logs\crash.log`；本版先把可观测性和托底补齐。
- Qoder 修复首次使用时会在子进程做一次自检（约 2 秒），之后走缓存。

# v1.75.0 更新说明

本版重心是 Docker 构建链路的镜像源自定义：国内网络直连官方 npm 源易超时，构建时可传参换镜像源，默认行为不变，海外用户零影响。

## Docker 构建

- **npm 镜像源可传参（新功能）**：gateway 镜像构建新增 `NPM_REGISTRY` 构建参数，官方源直连超时可传 `--build-arg NPM_REGISTRY=https://registry.npmmirror.com` 换镜像；docker compose 侧同步支持（`export NPM_REGISTRY=...` 后 `up --build` 即可）；不传默认仍为官方源

# v1.74.0 更新说明

本版重心是反代网关的**权限收敛与稳定性**：新增 Key 级渠道/模型白名单、瞬时错误原地重发、超时与重试参数可配置，同时修复号池状态落库一致性问题。

## 反代网关

- **Key 级白名单（新功能）**：每把 API Key 可分别限制「允许使用的渠道」与「允许调用的模型」，留空即不限制；白名单外的请求返回 403 并说明原因，Key 泄露时影响面可控。存量 Key 默认不限制，升级不失效
- **瞬时错误原地重发（新功能）**：上游 5xx / 网络抖动 / 超时等瞬时失败，先在当前账号上按配置次数重发吸收抖动，用尽后才换号，减少不必要的账号切换；次数与间隔可配置（默认重发 1 次、间隔 1 秒）
- **超时与重试参数可配置**：首字节超时（基础值/上限）、流式空闲超时、JSON 请求超时以及瞬时重发参数均可在配置中调整，无需改代码；留空或填 0 回退内置默认
- **模型目录批量启停**：管理页模型列表支持一键全部开启 / 全部关闭 / 反选，并新增状态筛选，模型多时不用逐个点
- **Key 参数整单校验**：创建 / 修改 Key 时，名称、每日额度、速率限制等参数先全量校验再落盘，非法输入整体拒绝，不会出现"存了一半"的半套配置

## 号池与稳定性

- **修复账号状态落库不一致**：消除选号过程中账号状态的重复写入路径，冷却到期、限流复活等状态只按实际变化落库，避免状态在库中来回抖动；同时省掉每轮选号的全池 UPDATE，号多时更快
- **号池同步加速**：跨机同步合并快照时消除了逐账号查询（几百个账号的同步每轮少几百次数据库查询）
- **设备指纹强化**：账号设备指纹改用强随机算法生成，避免因指纹随机性不足被上游误判为"同设备多账号"而触发风控

## 其他修复

- Anthropic 协议接入层：`tool_result` 中的图片与未识别内容块此前会被静默丢弃，现在会记录可追溯日志，排查问题有据可查

## 说明

- 累积包含 v1.73.3 的待确认收件箱修复；从旧版升级的机器建议直接更新到本版
- 白名单与超时/重试配置为设备本地配置，不参与跨机同步，各机器可独立调整
